# Student Management System

A full-stack Student Management System developed using React.js, Node.js, Express.js, and MongoDB.

## Live Demo

https://student-management-portal-sravani19.vercel.app/students

## Technologies Used
- React.js
- Node.js
- Express.js
- MongoDB Atlas
- CSS

## Features
- Add student records
- View student records
- Update student details
- Delete student records
